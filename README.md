# Quiz App

An interactive and fun quiz application built to test knowledge with instant results, score tracking and a clean user-friendly interface.

## ✨ Features
- Multiple choice questions with instant feedback
- Score tracking and final result screen
- Timer for each question
- Responsive design for mobile and desktop
- Clean and simple UI

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript

## 🚀 How To Run
1. Download / Clone this repository
2. Open `index.html` in any browser
3. Start the quiz and test your knowledge
4. No installation needed
